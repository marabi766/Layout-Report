# Contributing

Open an issue before a substantial change. Include Windows/InDesign versions, input/template types, logs, and a minimal reproduction.

Keep UI text English and preserve Persian RTL behavior, editable output, source safety, kashidas-off behavior, and strict success validation.

Run `node tests/flow-tests.cjs`, test on Windows and InDesign, verify outputs and Preflight, and update the Changelog and Project Memory. Do not add third-party fonts, templates, or artwork without confirmed redistribution rights.
